# Броня Крепка — Танковый форум

Фронтенд танкового форума для мужчин 30+. Тёмная тема, мобильная адаптация, чистый HTML/CSS/JS без фреймворков.

## Быстрый старт

Открой любой `.html` в браузере — сервер не нужен.

```
open feed.html
```

## Страницы

| Страница | Описание |
|----------|----------|
| `index.html` | Авторизация (логин, регистрация, восстановление пароля) |
| `feed.html` | Лента тем, фильтры, поиск, сайдбар |
| `topic.html?id=N` | Просмотр темы и постов, добавление ответа |
| `profile.html` | Танковый паспорт, аватар, достижения, экипаж |
| `profile.html?user=Имя` | Профиль другого бойца |
| `new-topic.html` | Создание новой темы |

## Фичи

- Тёмная тема «Броня на ночь» с сохранением в localStorage
- Аватар через загрузку файла (Base64 → localStorage)
- Черновики с автосохранением (800ms debounce)
- Экипаж (друзья) с добавлением/удалением
- Чат-виджет с историей сообщений
- Поиск по темам в реальном времени
- Адаптив от 320px
- Тосты, модалки, медали, рейтинг

## Технологии

- HTML5, CSS3 (CSS-переменные), Vanilla JS
- Без фреймворков и внешних зависимостей
- localStorage для состояния (тема, аватар, черновики, профиль, настройки, чат, экипаж)

## Разработка

Фронтенд ждёт бэкенд: аутентификация (JWT в httpOnly cookies), загрузка файлов, REST API.
