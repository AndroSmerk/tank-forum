# Броня Крепка — Танковый форум (Frontend)

## Контекст проекта
- Танковый форум для мужчин 30+.
- dark theme "Броня на ночь", mobile-first (320px+), pure HTML/CSS/JS (без фреймворков).
- JWT будет в httpOnly cookies; фронтенд использует `credentials: 'include'`.
- Бэкенда пока нет — все формы работают через заглушки (toast + redirect).

## Ключевые решения и соглашения

### Архитектура
- Multi-page (не SPA).
- Header/footer/chat вставляются через `components.js` — не дублировать в HTML.
- Порядок скриптов: `utils.js → theme.js → toast.js → modals.js → avatar.js → components.js → chat.js → (drafts.js, crew.js)`.
- `index.html` не использует `components.js` (своя разметка без хедера).

### Тёмная тема
- Хранится в `localStorage` по ключу `tank-theme`.
- Применяется через `data-theme="night"` на `<html>`.
- Тумблер — элемент с классом `.theme-toggle`.
- `theme.js` сам вешает click-обработчик через делегирование.

### Чат
- `localStorage` ключ `tank-chat-collapsed` (свёрнут/развёрнут).
- История сообщений: `tank-chat-messages` (массив объектов `{author, text, time}`, до 50 сообщений).
- Восстанавливается при загрузке страницы.
- Инициализируется в `chat.js` после того, как `components.js` вставил разметку.

### Черновики
- `localStorage` ключи формата `tank-draft-{name}`.
- Используют атрибуты: `data-draft` на форме, `data-draft-field` на полях, `data-draft-indicator` на индикаторе.
- Дебаунс 800ms. Восстанавливаются при загрузке. Очищаются при submit.

### Профиль и данные пользователя
- `tank-profile` — JSON с name, rank, rankClass, quote, profession, city, tank.
- Автоинициализируется дефолтами (Полковник_Медведь, ★★★ Полковник) при первом заходе на любую страницу.
- Редактируется через модалку в профиле → `saveProfile()`.
- Данные профиля подтягиваются в `topic.html` через `ensureProfile()` — имя и звание показываются в новых постах.
- Аватар: `tank-avatar` (Base64 data URL), подставляется на `[data-avatar="me"]` через MutationObserver.

### Настройки
- `tank-settings` — JSON с notify, replays, theme (boolean).
- Чекбоксы на profile.html. Сохраняются при изменении, восстанавливаются при загрузке.

### Поиск по темам
- Инпут `#headerSearch` в хедере.
- На `feed.html` — фильтрация `.topic-card` в реальном времени по заголовку, тегам, автору.
- На других страницах — Enter перекидывает на `feed.html?q=запрос`.
- Поддерживает `?q=` в URL — автозаполнение и фильтрация при загрузке.

### Тосты
- Глобальный объект `window.toast` с методами: `show(msg, type, duration)`, `success()`, `error()`, `warning()`.
- Типы: 'info' (по умолч.), 'success', 'error', 'warning'.
- Авто-dismiss (4s), клик для закрытия.

### Модалки
- Глобальный объект `window.modal` с методами `open(id)`, `close(id)`.
- Оверлей = `.modal-overlay`, содержимое = `.modal`.
- Закрытие по клику на оверлей и по Escape.

## Паттерны для продолжения разработки

### Стили
- Все цвета — через CSS-переменные из `base.css` (olive, steel, fire, gold палитры).
- Тёмная тема переопределяет только нужные переменные (bg, text, border, shadow).
- Использовать токены из `base.css`: `--text-primary`, `--bg-card`, `--border-color`, `--radius-md` и т.д.
- Для новых страниц: создать или расширить существующий CSS-файл; подключать все 6 CSS-файлов.

### JS
- Все скрипты в IIFE (кроме `utils.js` — голые функции).
- `utils.js` должен загружаться первым на всех страницах.
- Для новой функциональности: создать отдельный файл в `js/`, подключить на нужных страницах.

### Атрибуты для JS
- Кастомные атрибуты (`data-*`) для декларативного связывания: `data-draft`, `data-filter`, `data-category`, `data-tags`, `data-avatar`.

## Статус реализации

### Сделано
- **Авторизация** (`index.html`): логин / регистрация / восстановление пароля (заглушки).
- **Лента** (`feed.html`): 3 категории тем (6 общих, 5 тактических, 3 нытья), фильтры (все / непрочитанное / активные / гайды / нытьё), пагинация, сайдбар (Зал Славы, онлайн, статистика, достижения, кланы), модалка онлайн с поиском, виджет экипажа.
- **Поиск по темам**: фильтрация карточек по вводу, поддержка `?q=`, Enter → `feed.html?q=`.
- **Тема** (`topic.html`): динамический рендер из JS-объекта `TOPICS` по `?id=N`. Vent-режим через `?id=N&type=vent`. Добавление новых постов через форму ответа (сохраняются в сессии). Хлебные крошки, теги, авторская панель (аватар, имя, звание). Время и номер поста.
- **Профиль** (`profile.html`): паспорт (обложка, аватар, статистика), модалки: редактирование профиля (сохранение в localStorage), достижения (12 шт., прогресс-бары), штрафбат, управление экипажем. `?user=Имя` — чужой профиль (кнопки штрафбат/в экипаж). `?crew` — автооткрытие модалки экипажа.
- **Сохранение профиля**: `tank-profile` в localStorage. Автоинициализация дефолтов. Подтягивается в посты на topic.html.
- **Настройки профиля**: 3 чекбокса (уведомления, подписки, тема), сохраняются в `tank-settings`.
- **Новая тема** (`new-topic.html`): форма с категорией, тегами, телом, файлами; черновик; редирект на feed.html.
- **Управление экипажем**: модалка на profile.html (поиск/добавление/удаление), ссылки в хедере и сайдбаре, имена → `profile.html?user=Имя`. Данные в `tank-crew`.
- **Аватар**: FileReader → Base64 → `tank-avatar`. MutationObserver на `[data-avatar="me"]`. Fallback SVG.
- **Тёмная тема**: тумблер, `tank-theme`, CSS-переменные, скроллбар.
- **Чат-виджет**: свёрнуть/развернуть, отправка, стикеры. История сообщений сохраняется в `tank-chat-messages` (до 50).
- **Тосты**: 4 типа, анимация, автозакрытие, клик-закрытие.
- **Модалки**: overlay, Escape, блокировка скролла.
- **Черновики**: debounce 800ms, restore, clear на submit. `window.draftsInit()` для динамики.
- **Адаптив**: 320px+, 768px+, 1024px+, 1400px+.

### Не реализовано (ждёт бэкенда)
- Реальная аутентификация (сейчас `onsubmit="location='feed.html'"`).
- Загрузка файлов (сейчас placeholder).
- Реальные API-запросы (сейчас статика + toast-заглушки).
- Уведомления (счётчики, пуши).

### Ожидаемый API
Бэкенд должен:
- Устанавливать httpOnly cookie `access_token` (15 мин) + `refresh_token` (7 дней) через `Set-Cookie`.
- Фронтенд шлёт запросы с `credentials: 'include'`.
- REST API для: auth (login/register/refresh/logout), topics (CRUD, list, filter), posts (CRUD), profile (get/update), users (list, online), achievements, shtrafbat, crew/friends, stats.
- Категории: general, tactical, vent.

### Известные проблемы / TODO
- Нет бургер-меню на мобилках (кнопка есть, JS нет).
- `new-topic.html` кнопка "Сохранить черновик" вызывает submit формы (можно сделать чище).
- Нет счётчика уведомлений в хедере.
- Нет страницы списка пользователей / профиля другого бойца.
- Посты не сохраняются между перезагрузками (только в памяти сессии).
- Поиск работает только на существующих данных (нет запросов к API).
